## Selected work

**🎙️ Real-time AI conversation** · *Alyx AI*
Integrated multiple text and image generation models alongside TTS and STT for spoken conversation with an AI tutor. The hard part wasn't the model calls — it was keeping latency across the STT → inference → TTS chain low enough that a spoken exchange still feels like a conversation.

**🏨 Multi-tenant GraphQL API** · *Pathfinder Studios*
Multi-tenant GraphQL API in NestJS and PostgreSQL for a US sports-events hotel booking platform, integrating Google Maps and the Amadeus XML API. Tenant isolation where inventory is shared but pricing and availability rules are not became the core design constraint.

**🔄 Legacy platform migration** · *Stackfee*
Moved a travel agency off Classic ASP onto React/Next.js for the public site and .NET/Blazor for internal tooling, behind a .NET REST API — including a CMS and media manager built so non-technical staff could publish without engineering involvement.
